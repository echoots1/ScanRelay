ScanRelay 0.2.1 is a small update to 0.2.0.

## What changed

- A printer's own group is shown by name on the Printers page, and the form says what choosing one does: the printer lists that group's members instead of the default sync group.
- When a release has no signed module list, the Modules page says so in plain words. It used to report "GitHub answered 404".
- When an update is available, the Dashboard has a button that downloads the new installer. Settings has a "Check for updates now" button.
- Scheduled syncs that find nothing to change are no longer listed on the Runs page. The Dashboard and the Runs page say when the list was last checked.
- The Kyocera ECOSYS module is unchanged from 0.2.0 (version 0.2.0 of the module).

## Steps for this version

The normal update. Run the installer on the server as an administrator. Nothing else is needed. The Kyocera module you have keeps working; there is no need to add it again.
