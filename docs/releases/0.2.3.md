ScanRelay 0.2.3 adds what the Canon imageCLASS module needs. It changes nothing for Kyocera printers.

## What changed

- A module can now read something from a printer once and have it stored, encrypted, with that printer. When a printer's module has such a read, the printer's form on the Printers page shows a button for it.
- The Canon imageCLASS module (version 0.2.0 of the module) uses this. Its printers refuse a load for some minutes after an export, so the address book is read once with that button and every push is built from the stored copy. Reading works on a real MF642C. Loading has been tested against a mock printer only.
- The Modules page has an "Add or update modules" button that opens setup at its Modules step. Setup shows on the server's own screen, so the button is only offered, and only works, in a browser on the server itself. Windows asks for an administrator before setup opens. The button appears after this version's installer has run once, because the installer is what registers the link.
- A printer Windows lists under a generic driver name, such as "Canon Generic Plus UFR II", can now be added from the list: choose the module yourself, then test the connection to see the model the printer reports.
- The nightly check no longer treats a name the printer cut short, or an entry that cannot hold an email address, as a difference to repair.
- The Kyocera ECOSYS module is unchanged (version 0.2.0 of the module).

## Steps for this version

The normal update. Run the installer on the server as an administrator.

For a Canon imageCLASS printer:

1. On the printer, make one shared folder entry named exactly "ScanRelay", pointing at the ScanRelay share, with the printer account and its password from Settings, Printer account.
2. In ScanRelay, add the printer with its System Manager ID and PIN, press "Read the address book from the printer", and save.
3. Wait a few minutes, then push. A push straight after a read waits for the printer by itself for up to 3 minutes.

After changing the printer's address book by hand, read it again, or the next push puts back the copy ScanRelay holds.
