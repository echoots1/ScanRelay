ScanRelay 0.2.7 adds the Canon imageCLASS MF650C Series to the Canon module.

## What changed

- Canon imageCLASS module 0.2.2 lists the MF650C Series. Reading its address book and loading one back both work on a real printer.
- A sign-in the printer refuses now says why: the ID and PIN are incorrect, a rule on the printer stops it, or the printer sent the sign-in back without judging it, which usually means it wants the other of http and https.
- The Kyocera ECOSYS module is unchanged (0.2.0).

## Steps for this version

Run the installer on the server as an administrator and, in its Modules step, update the Canon imageCLASS module to 0.2.2.

For an MF650C Series printer: if its Remote UI answers on http only, either turn on TLS for the Remote UI on the printer, which is the better setting, or set the module value "secure" to "false" on that printer's form. Then add it like any other Canon: make the "ScanRelay" entry on the printer, press "Read the address book from the printer", save, wait a few minutes, and push.
