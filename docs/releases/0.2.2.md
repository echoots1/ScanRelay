ScanRelay 0.2.2 is a small update to 0.2.1.

## What changed

- When an update is available, the Dashboard has a button that downloads the new installer. Settings has a "Check for updates now" button.
- Scheduled syncs that find nothing to change are no longer listed on the Runs page. The Dashboard and the Runs page say when the list was last checked. Syncs that change something, and syncs a person starts, are listed as before.
- The Kyocera ECOSYS module is unchanged (version 0.2.0 of the module).

## Steps for this version

The normal update. Run the installer on the server as an administrator. Nothing else is needed.
