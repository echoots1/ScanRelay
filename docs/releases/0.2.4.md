ScanRelay 0.2.4 is a small fix to 0.2.3.

## What changed

- A printer Windows lists under a generic driver name, such as "Canon Generic Plus UFR II", can now be added from the list: choose the module yourself, then test the connection to see the model the printer reports.
- The printer form lists the models the chosen module covers.
- The modules are unchanged: Kyocera ECOSYS 0.2.0 and Canon imageCLASS 0.2.0.

## Steps for this version

The normal update. Run the installer on the server as an administrator. Nothing else is needed.
