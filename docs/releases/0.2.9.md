ScanRelay 0.2.9 stops a scanner's empty test files showing up as failed scans. It also carries everything in 0.2.8.

## What changed

- **An empty file left in a scan folder is cleared away quietly** after ten minutes, with no failed job and no alert. The Brother scanner writes an empty test file to check it can reach the folder, and cannot remove it again because the printer account may only create and write. These were showing up as failed scans with "The file stayed empty".
- From 0.2.8: a module built beside a newer app loads in this one, and the installer's file copy is sturdier. See the 0.2.8 notes.
- The modules are unchanged: Kyocera ECOSYS 0.2.0, Canon imageCLASS 0.2.2, Brother ADS 0.1.1.

## Steps for this version

The normal update. Run the installer on the server. Nothing else is needed.

Failed jobs that say "The file stayed empty" from before this version can be ignored; they were a scanner's test files, not scans.
