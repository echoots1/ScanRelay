ScanRelay 1.0.0 is the first version called finished. It does what 0.2.9 does; what changed is inside.

## What ScanRelay 1.0 is

A person picks their name at the printer, scans, and the file lands in their own OneDrive. ScanRelay is one Windows service with a web admin screen. It keeps each printer's list of people in step with a group in Entra, or with the people you assign.

Printers and scanners it has modules for:

- Kyocera ECOSYS M8124cidn
- Canon imageCLASS MF642C, MF643C, MF644C and the MF650C Series
- Brother ADS-4900W

## What changed since 0.2.9

- **The code was gone through from end to end.** Things written two or three times are now written once, code nothing used was removed, and the documentation was brought in line with the program. Nothing was meant to work differently, and every automated test passes, including a real install on Windows.
- **The three printer modules were rebuilt from the tidied code** and carry new version numbers so that each build can be told apart: Kyocera ECOSYS 0.2.1, Canon imageCLASS 0.2.3, Brother ADS 0.1.2. They have been tested against the stand-in printers. They have not yet been pushed to the real ones, so after updating a module, push to one printer and look at it before relying on it.

## Steps for this version

The normal update. Run the installer on the server. The database is left as it is.

The modules you have keep working without being updated. To take the rebuilt ones, tick them in the installer's Modules step, or later with "Add or update modules" on the Modules page.
