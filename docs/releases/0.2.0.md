ScanRelay 0.2.0 is the first release. It has run end to end on one real server, one Microsoft 365 tenant and one printer, a Kyocera ECOSYS M8124cidn. Treat it as an early version: the full server test in the docs has not been completed.

## What is in it

- Scans written by a printer are delivered to each person's OneDrive, under Documents/Scans.
- An Entra group, plus people added by hand, decides who can scan. A sync keeps each printer's address book matched to it.
- A web admin screen for setup, jobs, runs, printers, people, modules and settings, with Entra sign-in and an Admin and a Helpdesk role.
- A Kyocera ECOSYS module, tested on the M8124cidn. It uses the printer's network service, which Kyocera does not document.
- Each person's printer entry also carries their email address, so the printer's own scan to email works from the same entry. This can be turned off in Settings.
- A proxy address setting, for reaching the admin screen through a reverse proxy.

## Changed since the builds some people ran before this release

- A sign-in token issued moments after consent could be kept for an hour without its permissions, so group searches were refused. Fixed.
- One person with a locked OneDrive no longer fails the sync for everyone. They are skipped and listed.
- Alert emails go to each admin's mailbox address, not their sign-in name. The test email says who it was sent to.
- The admin, helpdesk and sync groups can be removed in Settings. Each says what removing it does first.

## Steps for this version

The normal update. Run the installer on the server as an administrator.

Add the Kyocera module from this release in the installer's Modules step, replacing the one you have. After the update, press Sync now: every entry is pushed once, because each gains an email address.

## Known limits

- The installer is not signed, so Windows shows an unknown publisher warning. Check the download against SHA256SUMS.txt.
- The Kyocera module cannot sign in to the printer's network service. Keep the printer's sign-in for that service off, and limit ports 9090 and 9091 on your network to IT's computers and the ScanRelay server.
- There is no Canon module yet.
