ScanRelay 0.2.8 adds a module for the Brother ADS-4900W scanner and makes the installer's file copy sturdier.

## What changed

- **A Brother ADS module (0.1.1), for the ADS-4900W.** Each person gets one "Scan to Network" profile on the scanner, pointing at their own folder. On a real scanner (main firmware 3.20) one profile was saved, a scan to it arrived, and the profile was cleared again. A full push from the app has not been tried yet.
- **The installer waits for the service's program to close before it copies files,** gives each file about half a minute instead of five seconds, and copies everything once more after a pause if a file still cannot be written. This is for the "copy" step failing and then working when tried again.
- **Modules can be published without a new version of ScanRelay,** and a module built beside a newer app now loads in this one. Before, a module asked for the exact copy of the module contract it was built with, and an app with an older copy refused it with "Could not load file or assembly ScanRelay.ModuleSdk".
- The Kyocera ECOSYS module (0.2.0) and the Canon imageCLASS module (0.2.2) are unchanged.

## Steps for this version

The normal update. Run the installer on the server.

To add a Brother ADS-4900W:

1. In the installer's Modules step, add the Brother ADS module.
2. The scanner holds 25 scan profiles in all. On the Printers page, add it, tick "Only the people assigned below" and assign the people who use it, or give it its own small group.
3. Put the scanner's Web Based Management password in the password box of the admin sign-in. The user name is not used. The scanner only takes a sign-in over https, which is the default.
4. Turn off Auto Start Scan mode on the scanner if it is on: the scanner refuses changes while it is.
5. Test the connection, then push.

Names are cut to 14 characters on the scanner. Profiles that are not ScanRelay's are left alone.
